# 🏷️ Gunting Batu Kertas

Website game gunting, batu, kertas untuk hiburan dan mengenang masa kecil.

## ✨ Fitur

- Bermain Gunting, Batu, Kertas melawan komputer
- Pilihan komputer dipilih secara acak
- Animasi pilihan komputer sebelum hasil ditampilkan
- Menampilkan hasil pertandingan (Menang, Kalah, atau Seri)
- Highlight pilihan pemain yang aktif
- Mencegah klik berulang selama animasi berlangsung
- Tampilan responsif dan mudah digunakan

## ⚙️ Teknologi

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM Manipulation
- Event Handling
- Async/Await
